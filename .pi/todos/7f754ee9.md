## COMPLETED ✓

### Root Cause
The opencode server v1.14.48's `/event` endpoint closes the SSE stream immediately after the `server.connected` event (sends HTTP chunked terminator `0\r\n\r\n`). Verified via raw TCP socket test. The `/global/event` endpoint keeps the stream open correctly.

### Changes Made
1. ✅ Upgraded `@opencode-ai/sdk` from 1.4.6 to 1.14.48
2. ✅ Changed `client.event.subscribe({ directory }, { signal })` → `client.global.event({ signal })`
3. ✅ Added `unwrapGlobalEvent()` function to filter events by directory
4. ✅ Added `GlobalEvent` type import
5. ✅ Fixed `todos.findIndex is not a function` bug (array guard)
6. ✅ Fixed comment in discord-bot.ts
7. ✅ Build passes, tested in runtime - SSE events flowing correctly
